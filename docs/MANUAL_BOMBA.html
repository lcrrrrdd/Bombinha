Visão Geral

Desarmar a bomba completando todas as 6 etapas antes que o timer de 5 minutos chegue a zero. Você tem 3 strikes (erros permitidos). Cada strike acelera o timer. Ao atingir 3 strikes ou zerar o tempo: explosão.

Regras Gerais

  • Timer: 5 minutos (contagem regressiva no display)
  • Strikes: Máximo de 3 erros. Cada strike acelera a contagem.
  • Últimos 30 s: O buzzer apita mais rápido como aviso crítico.
  • Vitória: Melodia de sucesso + LED verde aceso + display fixo.
  • Derrota: Alarme contínuo + display piscando + LEDs vermelhos.
⚠️ Atenção: Todas as etapas dependem do Número de Série exibido no display. O Serial é gerado 100% aleatoriamente a cada partida (4 caracteres: números, letras maiúsculas, minúsculas e símbolos). Consulte este manual durante a partida.

Número de Série (Âncora Universal)

SERIAL: K9#m
TEMPO: 04:58
ETAPA: CORTE O FIO
Strikes: 0/3

Formato: 4 caracteres aleatórios do conjunto completo ASCII imprimível (exemplo: K9#m, 7@B2, xZ$5). Cada caractere é sorteado independentemente. O Serial é a única fonte de verdade para todas as regras dinâmicas.

Etapa 1 — Fios (Corte Físico)

Existem 5 fios. Apenas um está correto. O fio alvo é determinado pelo 4º caractere do Serial (S[3]).

FioCorCondição de Corte
1VermelhoS[3] ASCII par (ex: '0','2','4','6','8','B','D','F','H','J','L','N','P','R','T','V','X','Z','b','d','f','h','j','l','n','p','r','t','v','x','z')
2AzulS[3] ASCII ímpar (ex: '1','3','5','7','9','A','C','E','G','I','K','M','O','Q','S','U','W','Y','a','c','e','g','i','k','m','o','q','s','u','w','y')
3VerdeS[3] é letra maiúscula (A-Z)
4AmareloS[3] é letra minúscula (a-z)
5LaranjaS[3] é dígito (0-9) ou símbolo (!@#$%^&*)
Dependência: A cor do fio cortado define o 2º dígito da senha (Etapa 2).

Etapa 2 — Senha (6 Dígitos)

Digite 6 dígitos no teclado. * apaga, # confirma. Cada dígito deriva do Serial e do estado do jogo:

PosiçãoRegra de GeraçãoFórmula / Lógica
D1Baseado no 1º caractere (S[0])(ASCII(S[0]) % 9) + 1 → resultado 1-9
D2Baseado na cor do fio cortado (Etapa 1)Vermelho=3, Azul=8, Verde=2, Amarelo=7, Laranja=4
D3Baseado no 3º caractere (S[2])(ASCII(S[2]) % 9) + 1 → resultado 1-9
D4Baseado no 2º caractere (S[1]) + Strikes((ASCII(S[1]) + Strikes*17) % 10) → 0-9
D5Baseado no 3º caractere (S[2])Se ASCII par → 5, se ímpar → 3
D6Baseado no resultado do Simon (Etapa 3)Acertou sequência completa = 1, Errou = 0
Dependências cruzadas: D2 depende da Etapa 1 (fio cortado). D4 depende dos Strikes atuais. D6 depende da Etapa 3 (Simon).

Etapa 3 — Simon Says

Quatro LEDs piscam em sequência com tons diferentes. Repita usando as teclas:

Tecla A — Vermelho (Grave)
Tecla B — Verde (Médio-Grave)
Tecla C — Amarelo (Médio-Agudo)
Tecla D — Laranja (Agudo)

Fluxo: o jogo exibe uma sequência → você repete → a cada acerto a sequência cresce. A semente da sequência é derivada de ASCII(S[1]) XOR ASCII(S[3]).

Para completar, acerte 5 cores seguidas.

Dependência: O resultado (acerto/erro) define o D6 da senha (Etapa 2).

Etapa 4 — Sintonizar Frequência

Gire o potenciômetro até encontrar o tom alvo. Quanto mais perto, mais agudo e rápido o buzzer apita. O display mostra apenas uma dica vaga.

Frequência alvo (Hz): 440 + (ASCII(S[0]) % 12) * 50 + (ASCII(S[2]) % 8) * 10

Exemplo SerialFrequência Alvo
K9#m (75, 57, 35, 109)440 + (75%12=3)*50 + (35%8=3)*10 = 440+150+30 = 620 Hz
7@B2 (55, 64, 66, 50)440 + (55%12=7)*50 + (66%8=2)*10 = 440+350+20 = 810 Hz

Etapa 5 — Chaves Toggle (4 Chaves = 16 Combinações)

4 toggles geram 16 possibilidades (binário 0000 a 1111, decimal 0-15).

  1. Base (4 bits): ASCII(S[0]) & 0x0F (4 bits menos significativos do 1º caractere).
  2. Modificador Fio (Etapa 1): Se o fio Azul (fio 2) foi cortado → XOR 0x0F (inverte todos os 4 bits). Senão, mantém.
  3. Modificador Strikes: Se houver ≥1 strike → some 1 (com carry). Se 0 strikes → mantém.
  4. Modificador Serial (S[3]): Se ASCII(S[3]) for primo → XOR 0x0A (inverte bits 1 e 3). Senão → mantém.

Exemplo prático (Serial K9#m):

Serial: K(75), 9(57), #(35), m(109)
1. Base: 75 & 0x0F = 0x0B = 1011 (decimal 11)
2. Fio Azul cortado? → Sim → 1011 XOR 1111 = 0100 (decimal 4)
3. Strikes = 1 → 0100 + 1 = 0101 (decimal 5)
4. 109 não é primo → mantém 0101
Chaves corretas: Desligado(0), Ligado(1), Desligado(0), Ligado(1) → 0101

Etapa 6 — Segurar e Soltar

Segure o botão grande e solte quando o timer mostrar o dígito alvo.

O dígito alvo é o D4 da senha (calculado na Etapa 2). Soltar cedo ou tarde = 1 Strike.

Exemplo Completo de Partida

Serial sorteado: K9#m

  1. Fios: S[3]=m (ASCII 109, ímpar, minúscula) → Fio 2 (Azul). Corte o fio azul. → D2 = 8.
  2. Senha:
    • D1: (75 % 9) + 1 = 4
    • D2: 8 (fio azul)
    • D3: (35 % 9) + 1 = 9
    • D4: ((57 + 0*17) % 10) = 7 (strikes=0)
    • D5: S[2]=35 (ímpar) → 3
    • D6: Aguarda Simon
    Senha parcial: 48973_
  3. Simon: Seed = 57 XOR 109 = 86. Sequência gerada: A-D-B-A-D. Jogador acerta → D6 = 1.
  4. Senha final: 489731
  5. Frequência: 440 + (75%12=3)*50 + (35%8=3)*10 = 620 Hz. Sintonize até o buzzer estabilizar.
  6. Chaves: Base 75&0xF=11 (1011) → Fio Azul inverte 0100 → Strikes=0 mantém → S[3]=109 não primo → 0100 (decimal 4) → Chaves: 0 1 0 0.
  7. Segurar e Soltar: D4 = 7. Segure o botão e solte quando o timer mostrar 7 nos segundos.

Resultado: Bomba desarmada. LED verde aceso. Vitória.
