Manual de Desarme

Simulador Eletrônico de Bomba • ESP32 WROOM-32D • 6 Etapas
💡 Versão 2.0 ⏰ Timer: 5 min 🚩 3 Strikes 📷 Serial Aleatório

🛠 Visão Geral

Desarmar a bomba completando todas as 6 etapas antes que o timer de 5 minutos chegue a zero. Você tem 3 strikes (erros permitidos). Cada strike acelera o timer. Ao atingir 3 strikes ou zerar o tempo: explosão.

⚠ Regras Gerais

  • Timer: 5 minutos (contagem regressiva no display)
  • Strikes: Máximo de 3 erros. Cada strike acelera a contagem.
  • Últimos 30 segundos: O buzzer apita mais rápido como aviso crítico.
  • Vitória: Melodia de sucesso + LED verde aceso + display fixo.
  • Derrota: Alarme contínuo + display piscando + LEDs vermelhos.
⛔ Atenção: Todas as etapas dependem do Número de Série exibido no display. O Serial é gerado 100% aleatoriamente a cada partida (4 caracteres: números, letras maiúsculas, minúsculas e símbolos). Consulte este manual durante a partida.

🚩 Número de Série (Âncora Universal)

SERIAL: K9#m
TEMPO: 04:58
ETAPA: CORTE O FIO
Strikes: 0/3

Formato: 4 caracteres aleatórios (exemplo: K9#m, 7@B2, xZ$5). Cada caractere é sorteado independentemente. O Serial é a única fonte de verdade para todas as regras dinâmicas.

O que cada caractere do Serial controla

PosiçãoCaractereOnde é usado
Primeiro caractereEx: KPrimeiro dígito da senha · fio base · chave base · frequência base
Segundo caractereEx: 9Quarto dígito da senha · sequência do Simon
Terceiro caractereEx: #Terceiro e quinto dígitos da senha · frequência extra
Quarto caractereEx: mFio alvo · sexto dígito da senha (via Simon) · chave extra

🚗 Etapa 1 — Fios (Corte Físico)

Existem 5 fios. Apenas um está correto. O fio alvo é determinado pelo quarto caractere do Serial.

FioCorCondição de Corte
1VermelhoQuarto caractere tem valor ASCII par
2AzulQuarto caractere tem valor ASCII ímpar
3VerdeQuarto caractere é letra maiúscula (A-Z)
4AmareloQuarto caractere é letra minúscula (a-z)
5LaranjaQuarto caractere é dígito (0-9) ou símbolo
💩 Dependência: A cor do fio cortado define o segundo dígito da senha (Etapa 2).

🖎 Etapa 2 — Senha (6 Dígitos)

Digite 6 dígitos no teclado. * apaga, # confirma. Cada dígito é calculado a partir do Serial e do estado do jogo:

PosiçãoComo calcularFórmula / Lógica
1º dígitoPrimeiro caractere do Serial(valor % 9) + 1 → resultado 1-9
2º dígitoCor do fio cortado (Etapa 1)Vermelho=3, Azul=8, Verde=2, Amarelo=7, Laranja=4
3º dígitoTerceiro caractere do Serial(valor % 9) + 1 → resultado 1-9
4º dígitoSegundo caractere do Serial + strikes((valor + strikes×17) % 10) → 0-9
5º dígitoTerceiro caractere do SerialValor par → 5 · valor ímpar → 3
6º dígitoResultado do Simon (Etapa 3)Acertou sequência completa = 1 · Errou = 0
🔍 Dependências cruzadas: O 2º dígito depende da Etapa 1 · O 4º dígito depende dos strikes atuais · O 6º dígito depende da Etapa 3 (Simon).

🎵 Etapa 3 — Simon Says

Quatro LEDs piscam em sequência com tons diferentes. Repita usando as teclas:

Tecla A — Vermelho (Grave)
Tecla B — Verde (Médio-Grave)
Tecla C — Amarelo (Médio-Agudo)
Tecla D — Azul (Agudo)

O jogo exibe uma sequência → você repete → a cada acerto a sequência cresce. A semente da sequência é derivada do segundo e quarto caracteres do Serial.

Para completar, acerte 5 cores seguidas.

💩 Dependência: O resultado (acerto ou erro) define o 6º dígito da senha (Etapa 2).

🎲 Etapa 4 — Sintonizar Frequência

Gire o potenciômetro até encontrar o tom alvo. Quanto mais perto, mais agudo e rápido o buzzer apita.

Frequência alvo (Hz): 440 + (primeiro caractere % 12) × 50 + (terceiro caractere % 8) × 10

Exemplo SerialFrequência Alvo
K9#m440 + (3×50) + (3×10) = 620 Hz
7@B2440 + (7×50) + (2×10) = 810 Hz

🔑 Etapa 5 — Chaves Toggle (4 Chaves = 16 Combinações)

4 toggles geram 16 possibilidades (binário 0000 a 1111, decimal 0-15). Siga esta ordem:

  1. Base (4 bits): pegue o primeiro caractere do Serial e use os 4 bits menos significativos.
  2. Modificador do fio: se o fio Azul (fio 2) foi cortado na Etapa 1, inverte todos os 4 bits. Senão, mantém como está.
  3. Modificador dos strikes: se houver 1 ou mais strikes, some 1 (com carry). Se tiver 0 strikes, mantém.
  4. Modificador do quarto caractere: se o valor do quarto caractere for número primo, inverte os bits 1 e 3. Senão, mantém.

Exemplo prático (Serial K9#m):

Serial: K(75), 9(57), #(35), m(109)
1. Base: 75 → 4 bits menos significativos = 1011 (decimal 11)
2. Fio Azul cortado? Sim → inverte 1011 para 0100 (decimal 4)
3. Strikes = 1 → 0100 + 1 = 0101 (decimal 5)
4. 109 não é primo → mantém 0101
Chaves corretas: Desligado(0), Ligado(1), Desligado(0), Ligado(1) → 0101

🚫 Etapa 6 — Segurar e Soltar

Segure o botão grande e solte quando o timer mostrar o dígito alvo.

O dígito alvo é o 4º dígito da senha (calculado na Etapa 2). Soltar cedo ou tarde = 1 Strike.

📧 Exemplo Completo de Partida

Serial sorteado: K9#m

  1. Fios: Quarto caractere é m (valor ímpar, letra minúscula) → Fio 2 (Azul). Corte o fio azul. → 2º dígito = 8.
  2. Senha:
    • 1º dígito: primeiro caractere K → (75 % 9) + 1 = 4
    • 2º dígito: 8 (fio azul)
    • 3º dígito: terceiro caractere # → (35 % 9) + 1 = 9
    • 4º dígito: segundo caractere 9 (valor 57), strikes=0 → (57 + 0) % 10 = 7
    • 5º dígito: terceiro caractere # é ímpar → 3
    • 6º dígito: aguarda Simon
    Senha parcial: 48973_
  3. Simon: semente do segundo e quarto caracteres. Sequência gerada: A-D-B-A-D. Jogador acerta → 6º dígito = 1.
  4. Senha final: 489731
  5. Frequência: 440 + (3×50) + (3×10) = 620 Hz. Sintonize até o buzzer estabilizar.
  6. Chaves: Primeiro caractere K → base 1011 → fio azul inverte para 0100 → strikes=0 mantém → quarto caractere não é primo → 0100 (decimal 4) → Chaves: 0 1 0 0.
  7. Segurar e Soltar: 4º dígito = 7. Segure o botão e solte quando o timer mostrar 7 nos segundos.

Resultado: Bomba desarmada. LED verde aceso. Vitória.
